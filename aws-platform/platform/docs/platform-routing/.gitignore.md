# .gitignore

[탐색 시작점](../ROUTING-README.md) · [원본 파일](../../.gitignore)

## 역할

운영자별 인벤토리·Vault와 실행 부산물을 Git에서 제외한다.

## 제외 범위

.vault*와 inventory/*.yml을 제외하고 hosts.example.yml은 예외로 유지한다. group_vars/all/vault.yml, retry·캐시·편집 부산물도 제외한다. 운영자 파일은 이번 문서 대응 대상에 포함하지 않는다.

플랫폼 디렉터리 아래의 .env·.env.*, 개인키·인증서 컨테이너(.pem·.key·.p12·.pfx), .aws/를 제외한다. 가상환경 .venv/·venv/와 Python 바이트코드 *.py[cod]도 제외한다. .env.example은 명시적 예외로 유지하며 실제 인증 값을 넣지 않는 공유 예시용이다. hosts.example.yml과 vault.example.yml도 공유 예시로 유지된다.

규칙을 추가해도 이미 추적 중인 파일은 자동으로 제외되지 않는다. 운영자가 git rm --cached로 추적만 해제하면 로컬 파일은 유지되며, 해당 삭제를 커밋한 이후부터 새 변경이 Git에 포함되지 않는다. 과거 커밋의 파일까지 제거하는 기능은 아니다.

## 검증 범위

이 문서는 현재 작업 파일의 선언·작업 이름·조건·참조를 대조했다. Ansible 실행, 템플릿 렌더링, 원격 서버 동작은 이번 문서 작업에서 검증하지 않았다. Python AST 스킬의 자동 심볼 검사는 이 파일 형식에 적용되지 않는다.
