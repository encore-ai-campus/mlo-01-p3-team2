# .gitignore

원본: .gitignore · [원본 파일](../../.gitignore) · [통합 목차](ROUTING-README.md)

## 역할과 현재 상태

로컬 Python 가상환경 `.venv/`, 모든 하위 경로의 `__pycache__/`, Python 컴파일 결과 `*.py[cod]`를 새 Git 추적 대상에서 제외한다. 코드, 문서, 테스트와 requirements 파일은 제외하지 않는다.

이미 Git이 추적 중인 파일에는 제외 규칙이 소급 적용되지 않는다. 현재 커밋에 포함된 가상환경과 캐시의 추적 해제는 별도 작업이며, 이 파일 추가로 로컬 파일이 삭제되지는 않는다.

## 선언과 검증 범위

Git 설정 파일이며 Python AST 분석 대상은 아니다. `git check-ignore --no-index`로 이미 추적 중인 파일에도 규칙이 일치하는지 검사한다. 실제 코드와 문서가 제외되지 않는지도 함께 확인한다.
