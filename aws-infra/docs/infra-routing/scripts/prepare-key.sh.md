# infra/scripts/prepare-key.sh

[탐색 시작점](../ROUTING-README.md) · [원본 파일](../../../infra/scripts/prepare-key.sh) · [공개키 설정](../config/README.md)

SSH 키가 없을 때 선택적으로 사용하는 Bash 스크립트다. 함수 선언 없이 본문이 실행되며 인수는 개인키 파일 경로 하나다.

1. 인수가 하나가 아니면 사용법을 출력하고 종료한다.
2. 상위 폴더가 없으면 생성하고 권한을 700으로 설정한다. 기존 폴더 권한은 바꾸지 않는다.
3. 개인키가 있으면 재사용한다. 없으면 ssh-keygen으로 RSA 4096비트 키를 만들며 암호 입력은 ssh-keygen이 처리한다.
4. 개인키 권한을 600으로 설정한다. 공개키가 없을 때만 개인키에서 복원하며 공개키 권한은 644로 설정한다.
5. Terraform에 지정할 공개키 경로를 출력한다. 개인키 내용은 출력하지 않는다.

개인키 경로는 저장소 밖으로 지정한다. 스크립트가 저장소 내부 경로를 자동으로 거부하는 검사는 없다. AWS 키페어 등록은 이 파일이 아니라 workload의 compute 모듈이 수행한다. 기존 공개키가 있으면 새 키를 생성할 필요가 없다.

이 문서는 원본 동작을 대조했다. 이번 문서 작성 과정에서 키 생성·권한 변경 또는 Bash 실행 테스트는 수행하지 않았다.
