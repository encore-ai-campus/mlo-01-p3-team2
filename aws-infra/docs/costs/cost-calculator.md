# 인프라 요금 계산 기준

계산 기준일은 2026-10-10이다. mysql-3 추가 후 서울 리전의 현재 설정에서 Bastion 포함 EC2 18대·EBS·ALB 1개·공인 IPv4 5개를 모두 24시간 유지하면 **기본 요금 소계는 약 $37.82**다. 실제 서비스 데이터 처리와 사용자 트래픽은 없는 조건이다. 원화는 **1달러=1,400원이라는 비교용 가정**으로 약 **52,950원**, 부가세 10%까지 적용한다고 가정하면 약 **58,245원**이다.

**현재 실제 AWS에는 account1 ALB가 없고, 사용자 요청에 따라 복원하지 않았다.** 같은 EC2·EBS·Bastion 실행 가정에서 ALB 0개·IPv4 3개로 계산하면 하루 **$37.04**, 31일 **$1,148.28**다. 이는 자원 수를 가정한 견적이며 실제 청구액 조회가 아니다. [MySQL 증설과 ALB 복원 보류 검증](../infra-routing/verification.md#2026-10-10-mysql-3-증설과-실제-aws-검증)

앞으로 수량·사양·디스크·운영 시간이 바뀌면 이 문서의 입력값과 계산 결과를 함께 갱신한다. 아래 값은 현재 설정을 바탕으로 한 견적이며 실제 청구액이나 크레딧 차감 후 결제액은 아니다. 이전 부하 시나리오는 [과거 견적](costs.md), 계정별 배치는 [자원 배분](account-allocation.md)을 참고한다.

## 다시 계산하는 방법

서버 실행 시간과 디스크·ALB·IP 유지 시간을 각각 넣는다. 예를 들어 EC2를 하루 9시간만 켜더라도 EBS·ALB·EIP를 그대로 두면 이 자원들은 24시간으로 계산한다.

```text
EC2 비용 = 각 사양의 수량 × 시간당 단가 × 실행 시간의 합
EBS 비용 = 각 볼륨의 GiB × 월 단가 × 유지 시간 / 해당 월 전체 시간의 합
ALB 기본료 = ALB 수량 × 시간당 단가 × 유지 시간
ALB 처리료 = 시간별 사용 LCU × LCU 시간당 단가의 합
공인 IPv4 비용 = 주소별 사용 또는 할당 유지 시간 × 0.005의 합

기본 소계 = EC2 + EBS + ALB 기본료 + ALB 처리료 + 공인 IPv4
확장 소계 = 기본 소계 + 유료 전송량 + S3 + 로그 + 백업 + 추가 서비스
원화 세전 = USD 소계 × 적용 환율
세금 10% 가정 금액 = 원화 세전 × 1.10
```

ALB의 1시간 미만 사용은 기본료 계산에서 한 시간으로 올림된다. EBS 유지 기간이 여러 달에 걸치면 각 달의 일수와 사용 시간을 나누어 합산한다. 크레딧은 계정별 적용 대상과 잔액을 확인한 뒤 반영한다. [ALB 과금 설명](https://aws.amazon.com/elasticloadbalancing/pricing/), [EBS 시간 비례 계산 예시](https://aws.amazon.com/ebs/pricing/)

트래픽이 생기면 사용자 수만 넣지 말고 ALB LCU, 인터넷 송신 GB, AZ 교차 통신량을 실제 사용량으로 추가한다. gp3의 기본 성능보다 높은 IOPS·처리량을 설정하거나 스냅샷을 보관하는 경우에도 별도 단가를 추가한다.
