### 계산 기준

- 기존 계산 구성: **EC2 18대, gp3 디스크 총 4,260GiB, Front EIP 2개, Bastion 자동 공인 IP 1개**. 16일 11:30부터 추가 게임 Backend t3.2xlarge·gp3 20GiB를 반영해 **19대·4,280GiB**로 계산합니다.
- EBS는 데이터가 찬 비율과 무관하게 **할당한 디스크 용량 전체**로 계산합니다. 중지 중에도 EBS·유지하는 EIP 비용을 더합니다.

- 아래 표는 과거 추정 이력으로 보존합니다. 새 비용은 문서 상단의 실제 기준 금액 이후 구간에만 추가합니다.
